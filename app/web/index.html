An AI that checks a claim across a packet of documents, and won’t guess when they disagree.

Give it a claim and a packet of insurance documents: the policy, its endorsements and binders. It shows where each document answers, quotes the clause on its page, and says which document wins and by which rule. When two of them conflict and no rule decides, it tells you that instead of picking one.

See it decide:

Most tools will answer whatever you paste. This one tells you which document wins, and tells you when it can’t tell.

The question is not “what does this policy say.” It is “which document says that, and does anything override it.” That second half is where people lose afternoons, and where an answer without a citation is worth nothing.

What you see

Every answer is a claim plus the assertions behind it. Each assertion carries its document, its place in it (a page, or character offsets in a text filing) and the exact quote, and a strength for every step: read straight off the page, derived by code from what was read, or judgment, from the model’s reading or a person’s identification. The weakest step is always named, so you know which part to check first.

A claim and its packet

The claim states one value: a retention, a special limit. The packet is everything that could govern it: the policy form, its endorsements, binders and schedules.

Each document is read where it applies

Only the part of each document that describes the claim's policy is admitted. The model reads it and points at the value; code parses the amount and checks the quote against the file.

A rule decides, or it refuses

An endorsement governs its base form; a later effective date governs an earlier one. When no rule applies and the documents disagree, nothing is picked. Every value is shown boxed on its page.

How it decides

Two documents speaking to the same thing get compared, not merged, and only on the same currency and basis. When a rule settles it, the rule is printed: an endorsement beats its base form, a later effective date beats an earlier one. When no rule applies, the answer is that it can’t be settled from these documents, and every pair carries its reason.

  • Supported. One document states it and nothing disputes it, or a rule names the document that governs.
  • Can’t be settled from these documents. They state different amounts and no rule decides, or the amounts match but can’t be compared on the same terms.
  • Not found. Nothing in the packet states a value for it.

Every answer above is one of these three. There is no fourth kind of answer where it guesses.

What it refuses

  • No answer without a citation: every value is a quote found, exactly, in the file.
  • No winner picked between documents that conflict, unless a rule decides.
  • No answer from outside the packet: if nothing in it states a value, the answer is not found.

What it can’t do yet

  • Small samples: one D&O program from an SEC filing, and eight homeowners packets.
  • Your own documents. Which policy each one describes is still labelled by hand, so uploads are off.
  • Tell you a claim is wrong. Comparing the governing value with the claim’s own value isn’t built.
  • Notice a missing document. If the policy that governs isn’t in the packet, it doesn’t say so yet.
  • Prove the endorsement rule on real packets. It has only fired where a script inserted the endorsement.

The results are in the repo, including the predictions it got wrong.

Questions

Is this another chatbot?

No. It checks one claim, and every value it reports is a quote checked against the file. The model reads and points; code compares numbers and applies precedence.

What if an answer is wrong?

Every value is boxed on its page so you can check it in seconds. A quote that cannot be found exactly on its page is rejected and never decides an answer.

Which documents work?

Two document families so far: a 1996 D&O filing from SEC EDGAR, and ISO homeowners forms (PDF). Uploads are not built yet, because which policy each document describes is still labelled by hand.

Does it replace my lawyer?

No. It checks a claim against the documents you give it. It does not give legal advice.
